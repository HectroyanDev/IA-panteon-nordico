# Aviso de PR demasiado larga

Un solo comentario general (no inline) cuando la PR supera las 1500 líneas cambiadas. Sin veredicto, sin aprobar ni pedir cambios. La primera línea (marcador) y el título son fijos: Tyr los busca para no repetir el aviso.

```
<!-- tyr:too-large -->
## ⚖️ Tyr · PR demasiado larga

Esta PR cambia {n} líneas (añadidas más borradas, sin contar lockfiles, `vendor/`, `dist/`, `build/`, archivos minificados, generados ni binarios). El límite para revisarla bien es 1500.

Es demasiado larga para revisarla de forma correcta, así que Tyr no la ha revisado ni ha dado veredicto. Conviene partirla en PRs más pequeñas y coherentes (por ejemplo, una por capa o por funcionalidad). Cuando cambie, Tyr la revisará.

🤖 Generated by Tyr-skill
```

- `{n}` es el recuento exacto del mapa de líneas cambiadas.
- En Bitbucket la primera línea puede no conservarse: el título `## ⚖️ Tyr · PR demasiado larga` más la firma bastan para reconocer el aviso.
- Si ya existe un aviso (marcador o título, con la firma), no se publica otro.
